# UnitedTails Code Samples

Selected **Unity / C#** code samples from my gameplay development work will be published here.

The focus is on **combat**, **companion and enemy AI**, and applying **Clean Architecture** to Unity gameplay code.

One part of this work is an experiment in taking Unity's distributed third-person movement code apart and reorganizing its responsibilities into a Clean Architecture structure. The original movement implementation comes from Unity; the architectural separation and subsequent gameplay work are my own.

## Planned samples

- Character actions, attacks, and combat interactions
- Companion and enemy targeting and behavior
- Examples of how gameplay logic is organized and connected to Unity components
- A case study of the third-person movement refactor, including the boundaries and trade-offs

I also work with **UniRx, UniTask, Zenject, and Cinemachine** when they fit the project.
